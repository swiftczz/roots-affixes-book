## 第 1 卷 · 阅读准备

### 第 1 章 印欧语系

**1. 为什么 two / duo / duo 同根?**
原始印欧语 *dwōu(二),分三支:

- 日耳曼路线:*d→*t(部分格林定律),→ 古英语 twā → 英语 `two`
- 拉丁:d→d 保留,→ `duo`
- 希腊:d→d 保留,→ `duo`

**2. tooth / dental 同根?**
原始印欧语 *h₃dónts(齿)。拉丁 dent- 保留 *d;日耳曼经过格林定律 *d→*t,变成古英语 tōþ → tooth。

**3. hound / canis / kyōn 同根?**
原始印欧语 *ḱwṓ(狗)。希腊 kyōn 保留 *k;日耳曼 *k→*h(格林定律),变成古英语 hund → hound;拉丁 canis 也来自同根(*k→c)。

### 第 2 章 五次关键输入

**1. kingly / royal / regal 三层**

- `kingly` 古英语(日耳曼):强调像国王、符合国王身份
- `royal` 经法语进入:王室的、官方王家的,搭配最广
- `regal` 拉丁来源:常强调庄严、威仪

三者并非只按正式度排列,也有不同搭配和核心意义。

**2. cow / beef 成对**
`cow` 延续本族动物名,`beef` 经法语进入并后来主要表示牛肉。诺曼征服后的社会分工有助于解释这一倾向,但法语词早期也可指动物,现代分工是长期词义变化的结果。

**3. tea 的传播路径**
它最终来自闽南语 `tê` 一类读音,但英语不是直接从厦门话借入,而是经荷兰语 *thee* 等海上贸易路线进入。许多使用 `cha/chai` 一类形式的语言走的是不同传播路线;不能简单概括成"海路一定是 tea、陆路一定是 chai"。

## 第 2 卷 · 拉丁之根

### 第 4 章 specere 家族

**1. expect = ex + spect**
向外张望、等候某人到来 → 期待。从"看出去等"演变成"期待"。

**2. circumspect = circum + spect**
四面环顾、处处留心看 → 谨慎。一个谨慎的人会"环顾四周"再行动。

**3. spectacular = spect + -acle + -ar**
字面义"值得看的"东西 + 形容词 → 壮观的。spectacle(奇观)+ -ar(形容词)。

### 第 5 章 ducere 家族

**1. aqueduct = aque + duct**
引导水的 → 渡槽。古罗马运水的拱形桥。

**2. seduce = se + duce**
引导分开 → 把人从正道上引开 → 引诱。

**3. deduce = de + duce**
向下引导 → 从一般原则向下推到具体 → 推断。

### 第 6 章 jacere 家族

**1. subject = sub + ject**
投向下 → 被压在下面的就是被支配的(使服从);放在下面的论题(主题)。

**2. object = ob + ject**
投向对方 → 抛到对方面前表示异议(反对);被抛在面前供观察的(物体)。

**3. trajectory = tra + ject + ory**
投越的 → 物体被"投掷"出去经过的路径 → 弹道。

### 第 7 章 capere 家族

**1. except = ex + cept**
抓出去 → 把某物从整体里抓出去 → 除外。

**2. intercept = inter + cept**
中间抓住 → 东西在传递过程中被截住 → 拦截。

**3. recipe = re + cipe**
医生处方开头写"取"(recipe)下列药材 → 后来泛化成食谱。

### 第 8 章 trahere 家族

**1. subtract = sub + tract**
从下拉走 → 从总数里"拉走"一部分 → 减去。

**2. retract = re + tract**
拉回来 → 把说出去的话"拉回"→ 撤回言论。

**3. treaty = treat + y**
处理的结果 → 国与国"处理"分歧后达成的协议 → 条约。

### 第 9 章 cor / mens / animus

**1. encourage = en + courage**
使有勇气 → 鼓励。把"心气"赋予别人。

**2. unanimous = un + anim + ous**
心意合一 → 投票时全员"心意合成一个" → 一致通过。

**3. record = re + cord**
放回心里 → 能记住的事才能记下来 → 记录。

### 第 10 章 mors 家族

**1. immortal 的对象**
神(希腊罗马宗教)、艺术作品(莎士比亚 sonnet)、伟大思想(柏拉图)被认为是不朽的。

**2. mortal / immortal 区分的影响**
西方文化由此发展出"超越必死性"的追求:宗教(永生)、艺术(流传后世)、哲学(精神不朽)。

**3. mortgage 一句话解释**
`mortgage` 是"死抵押",与收益可冲减债务的"活抵押"相对:抵押物收益本身不自动清偿本金。"还清或违约都会让契约死去"是后来的通俗故事,不是主要历史解释。

### 第 11 章 stare 家族

**1. persist = per + sist**
一直站着 → 风暴中站着不倒的人 = 坚持。

**2. constitution = con + stit + ution**
一起立起来 → 国家被"立起来"的根本大法 = 宪法。

**3. substance = sub + stant + ce**
底下站着的 → 支撑表面现象的根基 = 本质、物质。

### 第 12 章 lex / jus

**1. privilege 的现代例子**
免税(外交官)、特殊准入(会员制)、世袭权利(贵族)、法律豁免。

**2. jury 为什么要宣誓**
用誓言约束陪审员按正义(jus)说话,确保审判的公正。

**3. injure 的层次提升**
injure 把伤害从"物理事件"提升到"正义被违反"的道德/法律层面——伤害不只是身体损伤,更是权利的侵犯。

### 第 13 章 拉丁词根补遗

**1. compromise 的语义发展**
拉丁 *compromissum* 原指争议双方共同承诺把案件交给仲裁并接受裁决。由共同承诺解决争议,逐渐发展出相互让步并达成协议的现代含义。“共同向前送”只能助记字母,不能代替这条历史路径。

**2. prescribe vs proscribe**

- `prescribe`(规定、开处方):追溯到拉丁“预先写下、规定”,医学中专指写下治疗或用药指示。
- `proscribe`(禁止、取缔):追溯到“公开张贴、公布名单”,后来发展为宣布某人为法外之人或正式禁止。

**3. influence 与“流入”**
中世纪占星术把天体作用设想成流入人间的力量;这个“流入并产生作用”的概念后来一般化为现代“影响”。

## 第 3 卷 · 希腊之光

### 第 14 章 希腊语与科学术语

**1. telephone = tele + phone**
`tele-` 表"远",`-phone` 表"声音",组合起来指远距离传声装置。

**2. 为什么常用古典组合形式**
希腊语和拉丁语已有跨地区学术传统,组合形式便于多种欧洲语言共同采用。现代术语仍是多源系统,并非只用希腊语。

**3. biology 中的连接元音**
可以分析为 `bi- + -o- + -logy`,也可以把 `bio-` 作为完整组合形式再接 `-logy`;不能写成 `bio- + -o- + -logy`。

### 第 15 章 philo + sophia

**1. philanthropist 的责任**
字面"爱人类者"——富人意识到自己的财富来自社会,有责任回馈。这是慈善的道德基础。

**2. sophist 从褒到贬**
柏拉图等论敌对智者派的批判深刻影响后世,使 `sophist` 逐渐获得"诡辩者"贬义。智者派并非观点统一的群体,不能只用苏格拉底个人厌恶解释全部语义变化。

**3. sophomore = soph + moros**
聪明又愚蠢 → 大二生自以为懂了很多(聪明),实际还很幼稚(愚蠢)。命名带着对这个年纪的微妙调侃。

### 第 16 章 demo + cracy

**1. epidemic = epi + demo**
来自希腊 *epidēmios* "在人民中、在本地流行的"。核心是某现象在人群中普遍出现,不是疾病"压在人民头上"。

**2. aristocracy 的政治理想**
让"最优秀的人"(血统高贵、品德卓越)治国。这是寡头政治的辩护逻辑。

**3. bureaucracy 的讽刺**
"办公桌统治" → 讽刺官僚体系僵化、繁文缛节、效率低下。

### 第 17 章 神话与词汇

**1. psychology 中 `psych-` 的语义变化**
希腊 *psychē* 可表示气息、生命、灵魂或心灵,现代术语中的 `psych-` 则指心理、精神领域。古典成分解释了词形来源,却不能直接规定现代心理学的研究对象和方法。

**2. morphine = 梦神的药**
吗啡带来梦般的沉睡和止痛,药剂师 Sertürner 用梦神 Morpheus 命名,记录这种效果。

**3. tantalize = Tantalus 的折磨**
Tantalus 站水中"看得见够不着" → 引申为逗弄、吊胃口(让人渴望却得不到)。

### 第 18 章 -logy / -graphy / -metry

**1. biography = bio + graphy**
记录人生 → 把一个人的一生"写下来" → 传记。

**2. geometry 的实用起源**
`geometry` 字面与测量土地有关。希罗多德把几何知识与尼罗河泛滥后的土地丈量联系起来,但这是古代传统叙事;数学知识的形成涉及多个文明和长期发展。

**3. economy 与 *oikonomia***
希腊 *oikonomia* 指家庭或产业的安排、管理,后来经过长期语义扩展形成现代"经济"概念。它说明现代词义有历史起点,但不等于现代经济只是放大的家庭管理。

### 第 19 章 希腊词根补遗

**1. hydrogen = 产生水的**
氢气燃烧后产生水,化学家 Lavoisier 据此命名:hydro(水)+ gen(产生)。

**2. television 拉丁希腊混用**
19 世纪造词者不再严格遵守纯希腊/纯拉丁,tele-(希腊)+ vision(拉丁)混合,因为好读好懂。

**3. polyglot = poly + glot**
希腊 glotta(舌头、语言)→ polyglot = 多语言者、通晓多语的人。

## 第 4 卷 · 日耳曼之骨

### 第 20 章 日耳曼词的特性

**1. 经济原则**
高频词平均较短是一种统计倾向。沟通效率和语音弱化可能参与其中,但词源、构词结构和借入年代同样重要;`house` 从古英语起就很短,不能说它因频繁使用才缩短。

**2. 不规则动词反而稳定**
高频词被反复练习、代代相传,保留了古英语的变化方式;低频词反而被规则化(加 -ed)。不规则是高频的勋章。

**3. father / paternal 与格林定律**
原始印欧语 *pəter(父)。日耳曼路线 *p→f(格林定律),变 father;拉丁路线 *p 保留,变 pater → paternal。

### 第 21 章 维京人留下的词

**1. they/them 是借词**
古英语和古诺尔斯语在接触区长期共存,古诺尔斯第三人称复数形式逐渐扩散到英语。形式之间的区分度可能有作用,但不能把"更清晰"写成已经证实的唯一原因。

**2. window = 风眼**
古诺尔斯语 *vindauga* 由"风+眼"组成,指让风和光进入的开口。具体开在屋顶还是墙壁不能仅凭词形确定,"屋顶排烟孔"只是可能场景。

**3. husband = 房子的主人**
古代男性 = 家主(householder),负责供养家庭,所以"房子的主人"= 丈夫。

### 第 22 章 日耳曼词速查

**1. silly / nice 的漂移**
silly 从"幸福"漂到"愚蠢"(贬义化);nice 从"无知"漂到"好"(褒义化)。词义漂移方向取决于社会用法——频繁用作含糊褒义词,原义会被磨平。

**2. lord = 守面包的人**
古代社会以面包为核心食物,管面包的人 = 供养家庭的人 = 主人。反映了农业社会的结构。

**3. heart / cordial / cardiac 三兄弟**

- `heart`:日耳曼路线
- `cordial`:拉丁路线(来自 cor)
- `cardiac`:希腊路线(来自 kardia)

## 第 5 卷 · 法语之饰

### 第 23 章 诺曼征服

**1. 政治/法律词是法语**
诺曼征服后,法语在宫廷、行政和法律领域影响显著,因此这些领域吸收大量法语词;但拉丁语和英语也持续使用,不能说整个领域的词都是法语。

**2. 阶级烙印**
中世纪英格兰长期并用英语、法语和拉丁语,使用范围受领域、地区和身份影响。部分借词后来形成较正式语体,但需结合整词意义和搭配判断。

**3. 学术论文偏向长词**
学术写作应优先选择准确、清晰且符合学科惯例的词。长词或法语、拉丁来源词不天然更精确。

### 第 24 章 厨房里的征服

**1. pig / pork 成对**
`pig` 延续本族动物名,法语来源 `pork` 后来专指肉。阶层分工是解释这一趋势的背景之一,不是一幅农民饲养、贵族进餐的单一场景直接创造了词义。

**2. vinegar = 酸酒**
`vinegar` 字面来自法语"酸酒"。制醋是醋酸菌把酒精转化为醋酸的过程,不是普通酒精发酵简单"过头"。

**3. 不能说英语双层独有**
英语的动物/肉名词对很集中,与法语接触相关;其他语言同样可能用不同词、派生词或复合词区分动物和肉。

### 第 25 章 阶级的烙印

**1. kingly / royal / regal 风格差异**

- `kingly`:亲切、口语、本土
- `royal`:正式、官方
- `regal`:最庄严、文学性

**2. 英语三层词的原因**
英语的多来源近义词来自多个时期和路线,并非整齐三层。其他语言同样有继承词、借词、方言和专业语域。

**3. buy vs purchase**
日常购物用 buy(亲切);正式采购、商务合同用 purchase(正式)。

### 第 26 章 法语词根速查

**1. government = 掌舵**
古希腊 kybernan(掌舵)→ 拉丁 gubernare → 治理国家像驾驶船只。

**2. parliament = 谈话、讨论、会议**
古法语 *parlement* 原指说话、讨论,后来指会议和议会。`-ment` 在这里形成行为或结果名词,不是地点后缀。

**3. soldier / salary 的证据不同**
`soldier` 与 *solidus* 货币名称的联系较明确;`salary` 与盐词族有关,但罗马士兵直接领盐或购盐款缺乏可靠古代证据。

## 第 6 卷 · 词缀的故事

### 第 27 章 否定前缀

**1. un- vs in-**
`unhappy` 和 `invisible` 保存了不同历史构词路线,但现代英语没有强制同源匹配规则。`unacceptable`、`unscientific` 和 `amoral` 都是跨来源构词。

**2. dis- 更带对立**
dis- 含"相反动作",disagree 不只是"没同意",而是"主动持反意见"。

**3. malaria 与"坏空气"**
名称来自意大利语 *mal'aria* "坏空气",反映旧有病因观念;词形里没有另一个表示"疾病"的成分。疟疾实际由受感染的按蚊传播。

### 第 28 章 com-/con-

**1. compassion = 共同感受**
和别人一起感受痛苦,这就是同情的本质。对照希腊 sympathy。

**2. consent = 共同感觉**
两人有"共同感觉、共识",自然就是同意。

**3. corrupt 的 cor- 是强化形式**
拉丁 *corrumpere* 中的 `com-/cor-` 表强化,核心是"彻底破坏、败坏",不是"一起破"。

### 第 29 章 数字前缀

**1. September 是"第 7 月"**
`September` 保留 sept-"七",反映 March 曾作为年度起点的早期罗马历法传统。"后来在前面插入 January、February"是常见传统重建,早期历法细节并非完全可证。

**2. octopus = 八足**
章鱼有八条腕足,希腊 okto(八)+ pous(足)。

**3. quintessence = 第五元素**
中世纪四元素(土水气火)+ 第五元素(以太),第五元素最纯净高贵,引申为"精华"。

### 第 30 章 -tion

**1. decide / decision 的历史词干**
两词继承同一拉丁词族的不同词干。不是现代英语因 `d + tion` 发音别扭而临时删除 `d`。

**2. 学术论文用 -tion 名词**
名词化有助于压缩和指称复杂概念,但过度使用会降低清晰度。是否使用 `-tion` 名词应由句子功能决定。

**3. nation / question 发音不同**
question 词根含 s + t,发音演变特殊,读 /tʃən/;nation 读标准 /ʃən/。

### 第 31 章 -able

**1. readable 的条件**
字迹清楚、内容能被读懂、文风不晦涩。

**2. unbelievable 结构**
un(否定)+ believ(信)+ able(能被)= "不能被信的" → 难以置信。

**3. remarkable = 值得谈论**
remark(谈论、评论)+ able(值得)→ 值得被大家谈论的 → 非凡的。

### 第 32 章 -ism / -ist

**1. racism 的记录与传播**
目前词典记录可早至 1886 年;20 世纪 30 年代开始广泛传播。首次记录和流行年代必须区分。

**2. modern 三件套**
modernism(现代主义)、modernist(现代主义者)、modernize(现代化)。

**3. -ism 本身不带固定褒贬**
`racism` 等整词为负面,是因为它们命名歧视现象;`-ism` 仍可用于中性或依立场变化的学说、风格和状态词。

### 第 33 章 -ly

**1. -ly 的漂移**
古英语形容词后缀 `-līc` 与"身体、形态"词同源,其副词形式是 `-līce`。二者后来都弱化为 `-ly`,不能把现代 `quickly` 逐字译为"以快的身体"。

**2. friendly 是形容词**
-ly 加在名词 friend 后,形成形容词(像朋友的)。不是副词。

**3. 演变规律**
具体语义(身体)→ 抽象语义(方式),是语言演变的常见方向:**具体先于抽象**。

## 答案使用建议

思考题的三种用法:

1. **自测** —— 先不看答案,自己作答,然后对照
2. **复习** —— 每读完一卷,回头看思考题,检验理解
3. **讨论** —— 思考题多数是开放的,可以和朋友讨论,不必拘泥于"标准答案"

> 词源是有趣的话题,重要的是建立"探究为什么"的思维,而不是记住标准答案。
