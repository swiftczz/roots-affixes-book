# 附录 C:词缀与组合形式总索引

> 本索引不再用”不、前、后、自”这样的单字释义——那种极简风格适合路标,不适合认人。每项同时说明它在词中承担什么作用、常见语义方向和代表例词,好让你不只知道它姓什么,还知道它干什么。

**先区分三个概念**:

1. **前缀**放在词基前,主要改变方向、数量、否定或程度,如 `re- + write → rewrite`。
2. **后缀**放在词基后,常改变词性或表示人、状态、过程等,如 `kind + -ness → kindness`。
3. **组合形式**多来自希腊语或拉丁语,自身带有较具体的词汇意义,常用连接元音组合,如 `auto- + bio- + -graphy → autobiography`。

## 四、怎样使用这份索引

### 第一步:确认它真的是词缀或组合形式

看到相同字母不等于找到词缀。例如:

- `auto-` 在 `automatic`、`autobiography` 中确实表示“自身/自动”。
- `auto` 在单独书写时也可以是 `automobile` 的口语缩略,那是现代单词用法。
- `-ment` 在 `development` 中是名词后缀,但 `mental` 中的 `ment-` 属于“心智”词根。

### 第二步:组合出“临时解释”

```text
un- + predict + -able
不  + 预测    + 能够被……
→ 不能被预测的 → unpredictable

auto- + bio- + -graphy
自己  + 一生  + 书写/记录
→ 记录自己一生的作品 → autobiography

trans- + mit
跨越    + 送
→ 送到另一边 → transmit
```

### 第三步:回到整词的实际意义

词根词缀只能提供推测入口,不能替代词典和语境。`understand` 不能按现代 `under + stand` 译成“站在下面”,`department` 也不能因为含有 `art` 字母就解释成“艺术部门”。
