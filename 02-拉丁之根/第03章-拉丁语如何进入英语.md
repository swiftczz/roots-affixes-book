# 第 3 章 从台伯河到泰晤士河:拉丁语如何进入英语

> 拉丁语进入英语不是一次投递,而是四条跨世纪物流线。有的走陆路,有的搭教会的车,还有的先在法语仓库中转。

欢迎来到第 2 卷——**拉丁之根**。

这一卷集中讨论英语中数量庞大的拉丁来源词。在我们逐个家族展开之前,需要先回答一个总问题:

> **拉丁语是怎么进入英语的?罗马帝国曾统治不列颠的大部分低地地区,为什么罗马撤离以后,拉丁词仍持续进入英语?**

答案不是一次借入,而是几条跨越两千年的路线。本章用**大陆早期接触、基督教传播、法语中介和后期直接借词**四条路线来概括;实际边界会互相重叠,历史从来不肯乖乖排成四条互不串门的队伍。

---

## 3.1 第一条路线:大陆接触(公元 5 世纪前)

### 故事:还没去不列颠,日耳曼人就已经借了拉丁词

英语的祖先(古英语)还没成形之前,日耳曼部落还住在欧洲大陆——今天的德国北部、丹麦、荷兰一带。那时他们与罗马帝国比邻而居,通过**贸易、当兵、边境接触**,陆陆续续从拉丁语里借了一批词。

这些词进入日耳曼语时还很早,随后跟着盎格鲁-撒克逊人渡海到了不列颠,又经历古英语→中古英语→现代英语的连续演变——所以今天你**几乎认不出它们是拉丁词**,堪称词汇界的长期潜伏者。

```mermaid
flowchart LR
    A["日耳曼部落<br/>(欧洲大陆)"] <---> B["罗马帝国<br/>(边境贸易、当兵)"]
    B --> C["借入拉丁词<br/>并日耳曼化"]
```

| 拉丁词 | 英语词 | 含义 |
| ------ | ------ | ------ |
| `vinum` | wine | 酒 |
| `caseus` | cheese | 奶酪 |
| `mille` | mile | 英里(本义"千步") |
| `strata` | street | 路(本义"铺过的") |
| `coquina` | kitchen | 厨房 |
| `pondo` | pound | 磅(拉丁语中表示"按重量") |

特点:词短、已彻底融入、看不出拉丁血统。

> **提示** **这条路线的特点**:词形已经深度适应日耳曼语,今天往往看不出拉丁来源。这些词不是本书的主要拆词对象。

---

## 3.2 第二条路线:基督教传播(公元 597 年以后)

### 故事:那个金发少年和一个双关

故事的主角是教皇**格里高利一世(Pope Gregory I)**,时间大约在他登基之前。*(传说)* 某天,格里高利路过罗马的奴隶市场——那里人声嘈杂,熏香、汗味和牲口的气息混在一起。他无意中瞥见摊位上摆着几个待售的少年,立刻收住了脚步:那几个孩子**金发碧眼,皮肤白皙**,在一群深色头发的罗马人和棕色皮肤的东方奴隶中间,白得几乎发光,像是从别的世界掉进来的。

格里高利走过去,问商人:这些孩子是哪族人?
商人答:**盎格鲁人(Angli,Angles)。**

格里高利一听,愣住了——*Angli* 这个读音,几乎就是拉丁语 *angeli*(天使)。他盯着那几个金发少年,长叹一声,脱口而出一句后来被传诵千年的双关:

> **"Non Angli, sed angeli."**
> **"他们不是 Angles(盎格鲁人),而是 angels(天使)。"**

一句话出口,引出了一整套拉丁语谐音梗。他接着问:这些孩子来自哪个王国?答"**Deira**"(在今约克一带)——格里高利立刻接话:"那他们正该从 ***de ira***(神的愤怒)里被救出来!"又问他们的国王叫什么,答"**Ælle**"——格里高利又接:"那就该向他们唱 ***Alleluia***(哈利路亚)了!"一个未来的教皇,站在嘈杂的奴隶市场里,短短几句话连玩了三个谐音梗——**Non Angli/angeli、Deira/de ira、Ælle/Alleluia**——每一记都精准地踩在拉丁语的读音上。

*(传说)* 格里高利当场就想亲自去不列颠传教,被教廷拦下了。但他没忘这件事。**公元 597 年**,已升任教皇的他派出**圣奥古斯丁(St. Augustine of Canterbury——别和写《忏悔录》的圣奥古斯丁搞混,是另一个人)**,率领 40 名修道士,从罗马渡海到不列颠的**肯特王国**传教。修道士们扛着十字架、带着唱诗和一整套教会拉丁语,登上了肯特的海岸。

基督教化带来的不只是新宗教,还有一批**教会、教育和书写文化**相关的拉丁词——一次传教团,把整个书写传统也搬上了岛。

```mermaid
flowchart LR
    A["罗马教皇"] --> B["圣奥古斯丁"] --> C["肯特王国传教"] --> D["借入拉丁词<br/>(教会/学术)"]
```

| 拉丁词 | 英语词 | 含义 |
| ------ | ------ | ------ |
| `episcopus` | bishop /ˈbɪʃəp/ | 主教(经过古英语音变) |
| `presbyter` | priest | 神父(经过缩略) |
| `monachus` | monk | 修士 |
| `schola` | school | 学校 |
| `magister` | master | 大师 |
| `candela` | candle | 蜡烛 |

特点:词义多集中于宗教、教育,词形已发生不同程度变化。

> **提示** 这条路线里有个有趣现象:`bishop` /ˈbɪʃəp/(主教)最终追溯到希腊语 *epískopos*,经拉丁语及早期日耳曼语传播后进入古英语,词形已经大变;`episcopal` /ɪˈpɪskəpəl/ 后来经书面路线进入英语,保留了更明显的古典词形。两者是不同借入路径形成的同源双层词。

## 3.3 第三条路线:诺曼征服后的法语中介

1066 年以后,大量拉丁来源词不是直接从古典拉丁语进入英语,而是先在法语中演变,再随诺曼法语、英法语和后来的中央法语进入英语。`judge` /dʒʌdʒ/、`court`、`parliament` /ˈpɑrləmənt/、`royal` /ˈrɔɪəl/ 等都属于这条重要路线。

这条路线说明:**"拉丁来源"不等于"直接借自拉丁语"**。一个词可以有拉丁祖先、法语中间形态和英语中的新意义。

---

## 3.4 第四条路线:中世纪至近代的直接借词和古典造词

### 故事:一座城陷落,一船手稿漂向西方

前两波借入的拉丁词,数量有限、领域集中。真正让拉丁词根**铺满英语的学术、法律、医学、哲学领域**的,是**文艺复兴**。而点燃这场大火的导火索之一,是一场战争。

**1453 年 5 月 29 日,奥斯曼大军攻陷君士坦丁堡。** 这座城市是东罗马帝国千年的首都,也是希腊古典学术在欧洲最后的堡垒。城破那一刻,教堂的钟声被攻城的号角盖过,宫廷里的学者来不及收拾细软,**抱着成箱的羊皮纸手稿**冲向金角湾的港口。船帆一张,载着柏拉图、亚里士多德、荷马的希腊文原本,载着读懂它们的人,沿着地中海一路向西——佛罗伦萨、威尼斯、罗马,一座座意大利城市敞开城门接住了这批流亡学者。

他们带来的,是西欧人几百年没怎么见过的东西——柏拉图、亚里士多德、荷马的希腊文原本,以及读懂它们的能力。意大利的人文主义者像发现了宝藏一样扑了上去,**全欧洲掀起了一阵希腊语文献热**。学者们如饥似渴地翻译、研究,再用拉丁语把新概念重新打包,送往各国的大学和宫廷。后面英语里那一大批 `philosophy` /fəˈlɑsəfi/、`physics` /ˈfɪzɪks/、`democracy` /dɪˈmɑkrəsi/、`atmosphere` /ˈætməsˌfɪr/,根源都在这场文献大搬家。

*(文艺复兴的更广背景,见第 14 章"史实与传说"。)*

### 这一阶段的特点

学者和作者继续从拉丁语借词,也用拉丁、希腊组合形式创造新词。这一阶段常见的词有几个特点:

```mermaid
flowchart LR
    A["中世纪学术传统<br/>+ 人文主义<br/>+ 近代科学"] --> B["直接借词<br/>或用古典成分在近代语言中造词"]
```

相关词族示例(具体单词的中介路径并不完全相同):

| 拉丁词根 | 派生英语词 |
| ------ | ------ |
| `specere` | inspect / respect / suspect / spectator |
| `ducere` | conduct / produce / educate / introduce |
| `jacere` | eject / reject / project / inject |
| `capere` | capture / receive / concept / capable |
| `trahere` | attract / distract / tractor / retract |

特点:

1. 词明显更长(2-4 音节)
2. 词根清晰可辨(前缀 + 词根 + 后缀)
3. 许多用于书面、学术或专业语境
4. 是本书第 2 卷的"主战场"

> **为什么这条路线重要**:英语不仅借入完整词,也把一部分古典词缀和组合形式纳入了构词资源——这是本书后面"拆词"的根基。

## 3.5 多条路线合流:拉丁词在英语里的层次

四条路线讲完了。如果拉丁词会写简历,有的可以写"公元前入行,资历最老但面目全非",有的得写"经法语中介转岗,已更换工牌"。放在一起看看这张合照:

**拉丁来源词的四条常见路线**

| 路线 | 代表词 | 特点 |
| ------ | ------ | ------ |
| 直接借词/古典造词(中世纪至今) | inspect, educate, philosophy | 词长、词根清晰 |
| 法语中介(1066 年以后) | judge, court, parliament, royal | |
| 基督教传播(597 年起) | bishop, priest, school, candle | 中等长度 |
| 大陆接触(5 世纪前) | wine, cheese, mile, street, kitchen | 看不出是拉丁 |

### 学习启示

- **早期借词**(wine, cheese):词形已经深度日耳曼化
- **基督教借词**(bishop, school):体现长期宗教与教育接触
- **法语中介词**(judge, royal):需要同时观察拉丁祖形和法语音义演变
- **直接借词与古典造词**(inspect, philosophy):往往保留较明显的古典成分

## 3.6 为什么许多拉丁来源词较长

很多人疑惑:为什么拉丁来源的词总是这么长?古英语的 `give` 一个音节,拉丁来源的 `donate` /ˈdoʊˌneɪt/ 三个音节——好像拉丁词根出门必须穿全套西装三件套,而日耳曼词穿件T恤就上街了。这背后有一个结构性的原因。

拉丁语是高度屈折的语言,但英语借词通常不会把整套人称、格或时态词尾一起保留下来。许多拉丁来源词较长,更直接的原因是它们本来就是由前缀、词干和派生后缀组成的复杂词,而英语又在这些借词上继续派生。

**一个拉丁动词的"完整装备"**

拉丁词族:**educare**(养育、训练)

| 词干 | 说明 |
| ------ | ------ |
| `educ-` | 历史词干 |
| `-are` | 拉丁动词形式的一部分 |

英语借入 educate 后形成或接收一个词族:

| 词根 + 后缀 | 派生词 | 词性 |
| ------ | ------ | ------ |
| `educ` + `-ate` | educate | 动词:教育 |
| `educ` + `-ation` | education | 名词:教育 |
| `educ` + `-ational` | educational | 形容词:教育的 |
| `educ` + `-ator` | educator | 名词:教育者 |

→ 1 个拉丁词根,4-5 个英语派生词,长度自然就上去了。

因此,许多拉丁来源词比核心日耳曼词长,也更容易识别出重复的历史成分(至于"每一块是否都能拆",见本章末"史实与传说")。

## 3.7 拉丁词根的"变体"现象预告

这一卷里你会反复遇到一个现象:**同一个拉丁词根,在不同词里长得不一样**。

这些变体可能来自拉丁语不同词干、复合词中的元音变化,也可能来自法语的语音演变。不能把它们全部归为"现在时与过去分词"的区别。

**拉丁 capere(抓、取)的全家福**

| 变体形式 | 来源类型 | 例词 |
| ------ | ------ | ------ |
| `cap-` | 基本及派生形式 | capable, capacity |
| `capt-` | 分词/名词形式 | capture, captive |
| `cip-` | 复合弱化形式 | recipient, incipient /ɪnˈsɪpiənt/ |
| `cept-` | 复合分词形式 | concept, accept, except |
| `ceiv-` | 古法语路线 | receive, deceive, perceive |

多种历史形式,共享"取、抓、容纳"这一语义核心。

> **提示** **本卷会列出各词族的重要变体**。核心义能帮助提出拆解假设,但还要结合具体词形、传播路线和词义演变核对。

## 3.8 史实与传说

- **angles/angels 的双关故事属于教父传说。** 格里高利在罗马奴隶市场遇见金发盎格鲁少年并说出"非 Angles 乃 angels"的故事,出自比德《英吉利教会史》的记载,版本细节在不同抄本中有出入;它广为流传,但不必然是字面实录。
- **"四条路线"是叙事模型,不是四条互不相干的通道。** 同一个词可能同时沾上两条路线,四条边界本来就会重叠。君士坦丁堡陷落与文艺复兴的关系,第 14 章另作说明。
- **"每一块都能拆"过于绝对。** 拉丁词确实多由前缀+词干+后缀组成,但有些边界只在拉丁语史的特定阶段成立,有些现代英语词已经不能自由重组。能否造词,受历史惯例和实际语料约束——不是任意拉丁词根、前缀、后缀都能在现代英语里自由拼装。

## 3.10 本章小结

1. **拉丁词经多条路线进入英语**——大陆接触、基督教传播、法语中介和后期直接借词相互叠加。
2. **许多拉丁来源词结构较复杂**——但历史成分不等于现代英语里可以任意拼装的积木。
3. **同一词族常有多个变体**——要结合拉丁形态、复合变化和法语传递路线解释,不能只靠字母相似。
